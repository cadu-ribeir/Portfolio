💼 Meu Portfólio Pessoal

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica e profissional, experiências, formação, cursos, habilidades e projetos desenvolvidos na área de tecnologia.

O projeto tem como objetivo aplicar conceitos de desenvolvimento web, componentização, organização de código e criação de interfaces responsivas.

🚀 Tecnologias utilizadas
HTML5 — Estruturação das páginas.
CSS3 — Estilização e personalização visual.
Bootstrap 5 — Layout responsivo e componentes visuais.
Bootstrap Icons — Biblioteca de ícones.
JavaScript — Interatividade e funcionalidades.
Node.js — Ambiente de execução JavaScript.
Express — Gerenciamento de rotas e servidor.
EJS — Templates e componentes reutilizáveis.

📄 Páginas

O portfólio é organizado nas seguintes seções:

Início: apresentação pessoal e resumo profissional.
Experiências: histórico de experiências profissionais.
Escolaridade: formação acadêmica.
Cursos: cursos complementares e certificações.
Habilidades: competências técnicas e pessoais.
Desenvolvimentos: conhecimentos e tecnologias estudadas.
Projetos: apresentação dos projetos desenvolvidos.
⚙️ Instalação e execução
Pré-requisitos
Node.js
npm (gerenciador de pacotes do Node.js).
1. Clone o repositório
bash
git clone URL_DO_REPOSITORIO

2. Acesse a pasta do projeto
bash
cd Portfolio

3. Instale as dependências
bash
npm install

4. Execute o projeto
bash
npm start


Acesse no navegador:

text
http://localhost:3000

Certifique-se de que o script start esteja configurado no package.json, apontando para o arquivo app.js.
🎯 Objetivos do projeto
Desenvolver um portfólio pessoal e profissional.
Aplicar conceitos de HTML, CSS e Bootstrap.
Trabalhar com templates dinâmicos utilizando EJS.
Implementar componentes reutilizáveis.
Organizar o código seguindo boas práticas de desenvolvimento.
Desenvolver uma interface responsiva e intuitiva.
